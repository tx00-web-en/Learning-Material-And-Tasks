# Code Marathon 3 – Preparation Task

Before Code Marathon 3 session, complete the following preparation tasks with your group.

## 1. Complete today’s backend work

Ensure that the three backend API versions from Wednesday morning are completed:

* **Version 1:** No authentication
* **Version 2:** Authentication with User/Admin roles
* **Version 3:** Route protection

## 2. Complete today’s frontend work

Ensure that the three corresponding frontend versions are completed:

* **Version 1:** No authentication
* **Version 2:** Authentication with User/Admin roles
* **Version 3:** Route protection

## 3. Review the testing task

Review the testing task before the session.

**Testing task:** [link](https://github.com/tx00-resources-en/w7-exam-review/blob/main/api-testing.md)

Make sure your group understands the requirements and what needs to be implemented or tested.

## 4. Assign responsibilities

Before the session, decide who will be responsible for each part of the work.

### Backend

Assign responsibility for:

* Backend Version 1
* Backend Version 2
* Backend Version 3

### Frontend

Assign responsibility for:

* Frontend Version 1
* Frontend Version 2
* Frontend Version 3

### Deployment

Assign responsibility for deploying the **three full-stack application versions**.

> The deployment task is similar to the API deployment task, with some minor differences.

## 5. Prepare the Git repository

Before the session, decide:

* How many branches you will use
* What each branch will be used for
* Who will work on each branch
* How changes will be merged

Create the repository and the required branches **before the session**.

## 6. Agree on a workflow to avoid conflicts

Your group should agree on a process for working with Git and sharing code.

For example:

* Clearly assign tasks and files/components
* Avoid having multiple people modify the same files unnecessarily
* Pull the latest changes before starting work
* Commit changes regularly
* Communicate before merging changes
* Agree on how merge conflicts will be handled

## 7. Group collaboration

Agree on how your group will communicate and coordinate during the Code Marathon.

Everyone should know:

* Their assigned task
* Their branch
* Who is responsible for related tasks
* How to communicate blockers or problems
* How the group will review and integrate completed work

**The objective is to start tomorrow’s session with the technical work, responsibilities, repository structure, and collaboration workflow already prepared.**
