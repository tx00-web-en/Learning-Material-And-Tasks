# Badges

During the Coding Marathon, groups can earn badges by completing specific milestones within the given time limits.

Badges are awarded to the **whole group** and will be converted into the announced group bonuses.

There are three parts to the Coding Marathon.

---

## Part A: 09:45–12:00

Three badges are available:

### Part A: Fullstack First

Awarded to the **first group** to complete both the backend and frontend requirements for Part A.

### Part A: Testing First

Awarded to the **first group** to complete the required API testing for Part A.

### Part A: Deployment

Awarded to **every group** that successfully deploys the Part A full-stack application **before 12:00**.

---

## Part B: 13:00–16:00

Part B starts at **13:00**, giving all groups a new opportunity to compete for Part B badges.

Three badges are available:

### Part B: Fullstack First

Awarded to the **first group** to complete both the backend and frontend requirements for Part B.

### Part B: Testing First

Awarded to the **first group** to complete the required API testing for Part B.

### Part B: Deployment

Awarded to **every group** that successfully deploys the Part B full-stack application **before 16:00**.

---

## Part C: API Documentation

Part C is **optional**.

### API Documentation Badge

Awarded to **every group** that:

* has completed the required Part A and Part B work;
* completes the API documentation for the final API version; and
* submits the required deliverables to OMA **before 23:45**.

---

## ⏱Important
 
Each part is an **independent opportunity to earn badges**. Missing a badge in Part A does **not** prevent your group from earning badges in Part B or Part C.
